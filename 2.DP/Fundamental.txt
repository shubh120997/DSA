# Dynamic Programming (DP)

## Ways to Solve DP
1. Memoization (Top-Down)
2. Tabulation (Bottom-Up)

------------------------------------------------------------

## Fibonacci

Recurrence:
fib(n) = fib(n - 1) + fib(n - 2)

Base Cases:
fib(0) = 0
fib(1) = 1

Recursion Tree (n = 5)

                            fib(5)
                          /        \
                     fib(4)       fib(3)
                    /     \       /     \
               fib(3)   fib(2) fib(2)  fib(1)
               /   \     /   \   /   \
          fib(2) fib(1) f(1) f(0) f(1) f(0)
          /   \
      fib(1) fib(0)

Observation:
• Same subproblems are solved multiple times (**Overlapping Subproblems**).
• DP computes each subproblem once and reuses its result.

------------------------------------------------------------

## DP State & Container

State:
Changing parameter(s) of the recursive function.

Container:
Store one answer for each unique state.

Examples:
fib(n)         → dp[n]         (1D)
solve(i, j)    → dp[i][j]      (2D)
solve(i, j, k) → dp[i][j][k]   (3D)

Note:
Ignore parameters that remain constant (e.g., input array/string).

------------------------------------------------------------

## DP Transition

Write the recurrence relation for the current state.

Current State = Operation on Smaller States

Common Operations:
• max()
• min()
• +
• ||
• &&

Fibonacci:
fib(n) = fib(n - 1) + fib(n - 2)

------------------------------------------------------------

## DP Initialization

Memoization:
• Initialize DP with a sentinel value (e.g., -1).
• Return the stored value if already computed.

Tabulation:
• Initialize base case(s).
• Fill remaining states in dependency order.

------------------------------------------------------------

## 1. Recursion

```java
int fib(int n) {
    if (n <= 1)
        return n;

    return fib(n - 1) + fib(n - 2);
}
```

Time: O(2ⁿ)
Space: O(n) (Recursion Stack)

------------------------------------------------------------

## 2. Memoization (Top-Down)

```java
int fib(int n, int[] dp) {
    if (n <= 1)
        return n;

    if (dp[n] != -1)
        return dp[n];

    return dp[n] = fib(n - 1, dp) + fib(n - 2, dp);
}

// Driver
int[] dp = new int[n + 1];
Arrays.fill(dp, -1);

int ans = fib(n, dp);
```

Time: O(n)

Space:
• DP Array: O(n)
• Recursion Stack: O(n)

Total: O(n)

------------------------------------------------------------

## 3. Tabulation (Bottom-Up)

```java
int fib(int n) {
    if (n <= 1)
        return n;

    int[] dp = new int[n + 1];

    dp[0] = 0;
    dp[1] = 1;

    for (int i = 2; i <= n; i++)
        dp[i] = dp[i - 1] + dp[i - 2];

    return dp[n];
}
```

Time: O(n)
Space: O(n)

------------------------------------------------------------

## 4. Space Optimization

Idea:
Store only the states required to compute the current state.

```java
int fib(int n) {
    if (n <= 1)
        return n;

    int prev2 = 0;
    int prev1 = 1;

    for (int i = 2; i <= n; i++) {
        int curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }

    return prev1;
}
```

Time: O(n)
Space: O(1)

------------------------------------------------------------

## DP Checklist

1. Identify the DP State.
2. Write the Recurrence Relation (Transition).
3. Identify the Operation (max/min/+/||/&&).
4. Choose the DP Container.
5. Initialize DP.
6. Write Recursion.
7. Convert to Memoization.
8. Convert to Tabulation.
9. Optimize Space (if possible).
